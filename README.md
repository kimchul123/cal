# 개인 캘린더 (cal)

날짜를 클릭해서 그날 있었던 일을 자유롭게 적는 개인용 캘린더입니다.
엑셀로 쓰던 주간 일지 형식(주간목표 + 일별 자유 기록 + 색 구분)을 웹으로 옮긴 것입니다.

**바로 쓰기 → https://kimchul123.github.io/cal/**

빌드 도구나 서버가 필요 없습니다. `index.html` 을 브라우저로 열어도 그대로 동작합니다.

---

## 기능

| | |
|---|---|
| **월간 보기** | 한 달을 한눈에. 각 칸에 그날 기록이 미리 보입니다. |
| **주간 보기** | 일~토 7일을 나란히 놓고 칸 안에서 바로 타이핑. 위쪽에 **주간목표** 칸이 있습니다. |
| **자유 기록** | 날짜를 클릭하면 오른쪽에 편집창이 열립니다. 글자수 제한 없이 여러 줄로 씁니다. |
| **표시 색** | 일반 / **중요**(노랑) / **휴일**(빨강) / **완료**(회색) — 엑셀에서 쓰던 색 규칙 그대로입니다. |
| **번호목록** | 편집창의 `번호목록` 버튼이 `1 2 3 4 5 6` 틀을 넣어 줍니다. |
| **검색** | 상단 검색창에 단어를 넣으면 전체 기간에서 해당 기록을 찾아 줍니다. |
| **공휴일** | 신정·설날·삼일절·부처님오신날·어린이날·현충일·광복절·추석·개천절·한글날·크리스마스를 빨갛게 표시합니다. |
| **기기 간 동기화** | 회사 PC와 집 PC, 휴대폰이 같은 기록을 봅니다. 아래 설정 참고. |
| **백업 / 복원** | `⋯` 메뉴에서 JSON 내보내기 · 가져오기. |

### 단축키

| 키 | 동작 |
|---|---|
| `←` `→` | 이전 / 다음 (월간이면 달, 주간이면 주) |
| `T` | 오늘로 이동 |
| `/` | 검색창으로 |
| `Esc` | 편집창 닫기 / 검색 지우기 |
| `Ctrl`+`S` | 즉시 저장 |

## 기록이 저장되는 곳

기본적으로 기록은 **지금 쓰는 브라우저 안(localStorage)에만** 저장됩니다.
이 저장소는 공개이지만 앱 코드만 들어 있어서, 쓰신 내용이 인터넷에 공개되는 일은 없습니다.

다만 그대로 두면 **기기·브라우저마다 기록이 따로 놉니다.** 회사 PC에서 쓴 글이
집 PC에는 나타나지 않습니다. 양쪽을 맞추려면 아래 동기화를 켜세요.

---

## 기기 간 동기화 설정 (회사 PC ↔ 집 PC)

기록을 **내 비공개 저장소**에 두고 기기마다 자동으로 주고받게 하는 방식입니다.
기록은 비공개 저장소에만 들어가므로 남이 볼 수 없습니다.

### 1. 데이터 저장소 준비

비공개 저장소 하나가 필요합니다. [kimchul123/cal-data](https://github.com/kimchul123/cal-data)
가 이미 만들어져 있고 과거 엑셀 일지도 들어가 있습니다.

### 2. 액세스 토큰 만들기 (한 번만)

1. [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new) 를 엽니다
2. **Repository access** → `Only select repositories` → `cal-data` 선택
3. **Permissions** → `Repository permissions` → **Contents** 를 **Read and write** 로
4. 만들어진 토큰을 복사합니다 (이 화면을 벗어나면 다시 볼 수 없습니다)

> 토큰의 유효기간(Expiration)을 정할 수 있습니다. 만료되면 동기화가 멈추므로,
> 새 토큰을 만들어 다시 넣어 주시면 됩니다.

### 3. 기기마다 한 번씩 연결

캘린더 화면 위쪽 **`● 동기화 꺼짐`** 을 누르고 저장소 이름과 토큰을 넣은 뒤
`저장하고 연결` 을 누릅니다. 쓰시는 기기마다(회사 PC, 집 PC, 휴대폰) 한 번씩 하면 됩니다.

연결되면 글을 쓸 때마다 몇 초 뒤 자동으로 올라가고, 창을 다시 열 때마다 내려받습니다.
`⋯ → 지금 동기화` 로 직접 시킬 수도 있습니다.

### 합쳐지는 방식

같은 날을 두 PC에서 고쳤다면 **나중에 고친 쪽이 남습니다.** 한쪽에만 있는 날은
그대로 보존되므로, 다른 PC의 기록이 사라지지 않습니다. 올리기 전에 항상 먼저
내려받아 합치기 때문에, 회사에서 쓴 글이 집 PC의 오래된 사본에 덮이는 일은 없습니다.

한 가지 조심할 점은 **양쪽 PC의 시계가 맞아야** 최신 판단이 정확하다는 것입니다.
보통은 자동으로 맞으므로 신경 쓰실 일은 없습니다.

### 토큰은 어디에 저장되나요

토큰은 그 브라우저의 localStorage 에만 저장되고 다른 곳으로 전송되지 않습니다.
그래도 **공용 PC나 남의 PC에서는 넣지 마세요.** 쓰지 않게 되면
동기화 창의 `연결 해제` 를 누르고, GitHub 설정에서도 토큰을 지우시면 됩니다.

### 동기화를 안 쓰실 때

`⋯ → JSON 내보내기` 로 파일을 받아 두었다가, 다른 기기에서
`⋯ → JSON 가져오기` 로 불러오면 수동으로 옮길 수 있습니다. 동기화를 켜두셔도
가끔 내보내기로 백업해 두시면 마음이 편합니다.

## 엑셀 일지 가져오기

기존 엑셀 일지의 첫 번째 시트를 앱 형식으로 바꾸는
변환기가 [tools/xlsx-to-json.ps1](tools/xlsx-to-json.ps1) 에 있습니다. Windows PowerShell만 있으면 됩니다.

```powershell
# 1) xlsx 는 zip 이므로 압축을 풉니다
Copy-Item "일지.xlsx" "$env:TEMP\book.zip"
Expand-Archive "$env:TEMP\book.zip" -DestinationPath "$env:TEMP\book" -Force

# 2) 변환
.\tools\xlsx-to-json.ps1 "$env:TEMP\book" ".\data-local\diary-import.json"
```

그다음 앱에서 `⋯ → JSON 가져오기` 로 `diary-import.json` 을 고르면 됩니다.

변환기가 읽는 시트 구조는 3행이 한 주입니다.

```
1행  (비어있음/주간목표)   날짜  날짜  날짜  날짜  날짜   ← 엑셀 날짜값
2행  (비어있음)           일요일 월요일 화요일 …          ← 요일 이름
3행  주간목표 내용         기록  기록  기록  …            ← 자유 기록
```

날짜 칸의 배경색으로 표시를 정합니다. 빨강 → 휴일, 노랑 → 중요, 초록 → 주간목표.

> **변환 결과는 `data-local/` 에 저장되고 `.gitignore` 로 막혀 있습니다.**
> 과거 일지에는 고객사·동료 이름과 연락처가 들어 있으므로 이 폴더는 저장소에 올리지 마세요.

## 공휴일 표 고치기

음력 공휴일(설날·추석·부처님오신날)은 해마다 날짜가 달라 표로 관리합니다.
[assets/holidays.js](assets/holidays.js) 의 `LUNAR` 에 **2018~2027년**이 들어 있습니다.

- 2028년 이후를 쓰려면 그 해의 설날·추석·부처님오신날 날짜를 한 줄 추가하세요
- 대체공휴일은 해마다 정부 지정이 달라 자동 계산하지 않습니다. 필요하면 `EXTRA` 에 직접 적으세요
- 표에 없어도 편집창에서 **휴일** 표시를 누르면 그 날이 빨갛게 됩니다
