# 개인 캘린더 (cal)

날짜를 클릭해서 그날 있었던 일을 자유롭게 적는 개인용 캘린더입니다.
엑셀로 쓰던 주간 일지 형식(주간목표 + 일별 자유 기록 + 색 구분)을 웹으로 옮긴 것입니다.

**바로 쓰기 → https://kimchul123.github.io/cal/**

빌드 도구나 서버가 필요 없습니다. `index.html` 을 브라우저로 열어도 그대로 동작합니다.

---

## 기능

| | |
|---|---|
| **월간 보기** | 한 달을 한눈에. 각 칸에 그날 기록이 미리 보입니다. |
| **주간 보기** | 일~토 7일을 나란히 놓고 칸 안에서 바로 타이핑. 위쪽에 **주간목표** 칸이 있습니다. |
| **자유 기록** | 날짜를 클릭하면 오른쪽에 편집창이 열립니다. 글자수 제한 없이 여러 줄로 씁니다. |
| **표시 색** | 일반 / **중요**(노랑) / **휴일**(빨강) / **완료**(회색) — 엑셀에서 쓰던 색 규칙 그대로입니다. |
| **번호목록** | 편집창의 `번호목록` 버튼이 `1 2 3 4 5 6` 틀을 넣어 줍니다. |
| **검색** | 상단 검색창에 단어를 넣으면 전체 기간에서 해당 기록을 찾아 줍니다. |
| **공휴일** | 신정·설날·삼일절·부처님오신날·어린이날·현충일·광복절·추석·개천절·한글날·크리스마스를 빨갛게 표시합니다. |
| **백업 / 복원** | `⋯` 메뉴에서 JSON 내보내기 · 가져오기. |

### 단축키

| 키 | 동작 |
|---|---|
| `←` `→` | 이전 / 다음 (월간이면 달, 주간이면 주) |
| `T` | 오늘로 이동 |
| `/` | 검색창으로 |
| `Esc` | 편집창 닫기 / 검색 지우기 |
| `Ctrl`+`S` | 즉시 저장 |

## 기록이 저장되는 곳 — 꼭 읽어 주세요

기록은 **지금 쓰는 브라우저 안(localStorage)에만** 저장됩니다.
서버로 전송되지 않고, 이 저장소에도 올라가지 않습니다. 그래서:

- ✅ 내용이 인터넷에 공개되지 않습니다 (이 저장소는 공개이지만 앱 코드만 들어 있습니다)
- ⚠️ **기기·브라우저마다 기록이 따로입니다.** PC에서 쓴 글이 휴대폰에 나타나지 않습니다
- ⚠️ 브라우저 방문기록·쿠키를 완전히 지우면 기록도 함께 지워집니다

그래서 **주기적으로 `⋯ → JSON 내보내기`로 백업**하시고, 받은 파일을
구글 드라이브 같은 곳에 두시길 권합니다. 다른 기기에서는 그 파일을
`⋯ → JSON 가져오기`로 불러오면 그대로 이어서 쓸 수 있습니다.

## 엑셀 일지 가져오기

기존 엑셀 일지의 첫 번째 시트를 앱 형식으로 바꾸는
변환기가 [tools/xlsx-to-json.ps1](tools/xlsx-to-json.ps1) 에 있습니다. Windows PowerShell만 있으면 됩니다.

```powershell
# 1) xlsx 는 zip 이므로 압축을 풉니다
Copy-Item "일지.xlsx" "$env:TEMP\book.zip"
Expand-Archive "$env:TEMP\book.zip" -DestinationPath "$env:TEMP\book" -Force

# 2) 변환
.\tools\xlsx-to-json.ps1 "$env:TEMP\book" ".\data-local\diary-import.json"
```

그다음 앱에서 `⋯ → JSON 가져오기` 로 `diary-import.json` 을 고르면 됩니다.

변환기가 읽는 시트 구조는 3행이 한 주입니다.

```
1행  (비어있음/주간목표)   날짜  날짜  날짜  날짜  날짜   ← 엑셀 날짜값
2행  (비어있음)           일요일 월요일 화요일 …          ← 요일 이름
3행  주간목표 내용         기록  기록  기록  …            ← 자유 기록
```

날짜 칸의 배경색으로 표시를 정합니다. 빨강 → 휴일, 노랑 → 중요, 초록 → 주간목표.

> **변환 결과는 `data-local/` 에 저장되고 `.gitignore` 로 막혀 있습니다.**
> 과거 일지에는 고객사·동료 이름과 연락처가 들어 있으므로 이 폴더는 저장소에 올리지 마세요.

## 공휴일 표 고치기

음력 공휴일(설날·추석·부처님오신날)은 해마다 날짜가 달라 표로 관리합니다.
[assets/holidays.js](assets/holidays.js) 의 `LUNAR` 에 **2018~2027년**이 들어 있습니다.

- 2028년 이후를 쓰려면 그 해의 설날·추석·부처님오신날 날짜를 한 줄 추가하세요
- 대체공휴일은 해마다 정부 지정이 달라 자동 계산하지 않습니다. 필요하면 `EXTRA` 에 직접 적으세요
- 표에 없어도 편집창에서 **휴일** 표시를 누르면 그 날이 빨갛게 됩니다
