기기 간 동기화

회사 PC와 집 PC에서 같은 기록을 보려면, 기록을 내 비공개 GitHub 저장소에 보관하면 됩니다. 아래 두 칸만 채우면 이 브라우저가 그 저장소와 자동으로 주고받습니다.

토큰 만드는 방법
  1. github.com/settings/personal-access-tokens/new 를 엽니다
  2. Repository access → Only select repositories → 위에 적은 데이터 저장소를 고릅니다
  3. Permissions → Repository permissions → Contents 를 Read and write 로 바꿉니다
  4. 만들어진 토큰을 복사해 위 칸에 붙여넣습니다

토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않습니다. 그래도 남의 PC나 공용 PC에서는 넣지 마시고, 쓰지 않게 되면 GitHub에서 토큰을 지워 주세요.
